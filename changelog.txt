v2.5.0
- Settings option to disable resue of language invoker.
- Filter by country of orign and language.

v2.4.0
- Settings are three tabs: General, Filters, and Skin. Each tab is one list. Filters holds the settings that drop items from a list. API keys are on General. The two Advanced settings are on the other tabs. Stored values are kept.
- API keys are labelled TheMovieDB, OMDb, and Trakt.tv.
- "Allow items of the next [n] days" is shown only while "Hide upcoming items" is on.
- A new install starts the rating filter at 4.0 and the votes filter at 5. An existing install keeps its stored values until Defaults is pressed.
- The votes slider runs from 0 to 500 in steps of 5.
- The person chooser opens only when more than one result matches the name exactly and none is clearly better known.
- Resolved actor names are remembered. General has "Forget remembered actors" to clear a wrong match.
- Every toggle on the Skin tab has help text. Installing the context menu add-on says Kodi must be restarted before the entry appears.
- The rating badge sits further in from the corner of a poster.

v2.3.0
- Renamed from "Embuary Info (Kontell)" to "Embuary Info". The summary and description still identify this fork.
- Archive footage is recognised in any genre.
- New setting to hide items TheMovieDB rates below a chosen score, on a 0-10 slider in steps of 0.1. Unrated items are kept.
- New setting to hide items with fewer TheMovieDB votes than a chosen number, on a 0-5000 slider in steps of 100.
- Both filters apply to a person's credits, similar titles, and collection members.
- TLS is loaded on the first request that needs it.

v2.2.0
- Settings are four tabs: General, Skin, API keys, and Advanced. Descriptions are help text. Stored values are kept.
- Appearances as themselves match any wording TheMovieDB uses. Named voice parts in documentaries are kept.
- The same credit filters apply to television.
- New settings to hide documentaries, and to hide releases the person did not live to see.
- Posters in Similar, Collection, Seasons, Movies, and TV shows show the rating with the current skin's badge.
- The Skin tab has a toggle for each button a skin offers for this add-on, and adds Search.
- Opening a page is faster. The info dialog imported its libraries on every launch.
- Fixed movie pages with an OMDb key set: three requests per page, none of them cached, and an empty retail date.

v2.1.0
- Fork of sualfred's Embuary Info, based on unreleased upstream 2.0.10 (20 commits past released 2.0.8).
- Fixed memory growth while browsing. Pages stayed resident for the session, and a long session could run Kodi out of memory.
- Artwork is requested at a size the display can use.
- Faster page loads: a shared HTTP connection, parallel time-bounded trailer checks, and indexed local-library matching.
- Fixed a crash in date_year() when a date failed to parse.
- Fixed an error check that reported "not found" when results had been found.
